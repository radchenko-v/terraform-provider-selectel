# selectel_compute_snapshot_v3

Provides a network volume snapshot in Cloud Servers. The data source searches the snapshots in the project and pool by the specified filters and does not accept a snapshot ID. If you omit all filters, the data source searches all snapshots. A search that returns no snapshots fails. A search that returns multiple snapshots fails unless `most_recent` is `true`. For more information about snapshots, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/volumes/snapshots/).

## Example Usage

```terraform
data "selectel_compute_snapshot_v3" "snapshot_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-1"
  name       = "snapshot-1"
  volume_id  = selectel_compute_volume_v3.volume_1.id
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/).
- `region` (String) Pool where the snapshot is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/).

### Optional

- `most_recent` (Boolean) Specifies if the data source selects the snapshot with the latest `created_at` timestamp when multiple snapshots match. If `false`, the search must return exactly one snapshot. If several matching snapshots have the same latest timestamp, the data source selects any of them. The default value is `false`.
- `name` (String) Exact name of the snapshot to search for. If omitted, contains the name of the found snapshot.
- `status` (String) Exact status of the snapshot to search for, for example, `available`. If omitted, contains the status of the found snapshot.
- `volume_id` (String) Unique identifier of the source network volume to search snapshots for. If omitted, contains the ID of the source network volume of the found snapshot. You can retrieve the ID with the [selectel_compute_volume_v3](https://registry.terraform.io/providers/selectel/selectel/latest/docs/data-sources/compute_volume_v3) data source or from the [selectel_compute_volume_v3](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/compute_volume_v3) resource.

### Read-Only

- `description` (String) Snapshot description.
- `id` (String) Unique identifier of the found snapshot.
- `metadata` (Map of String) Snapshot metadata returned by the Block Storage API.
- `size` (Number) Snapshot size in GB.
